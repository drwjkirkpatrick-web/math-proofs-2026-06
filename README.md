# math-proofs-2026-06

A 2026 backlog of mathematics proofs — worked longhand, kept as a durable record.

> **Status:** skeleton. This repository was initialized 2026-09-22 as a
> placeholder/backlog for the June 2026 proofs effort; the working notes
> live elsewhere and the backlog has not yet been populated into this repo.
> The structure below is the intended layout once they land.

## Intended layout

```
backlog/        # open problem statements and proof sketches
proofs/         # completed proofs (one file or dir per result)
notes/          # side calculations, dead ends, and commentary
```

## Conventions

- One directory per result; state the claim, then the proof.
- Dead ends stay — they are part of the record.
- Longhand-first: the repository mirrors the notebook, it does not replace it.
